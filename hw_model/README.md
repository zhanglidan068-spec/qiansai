## 固定资源合同

| 项目 | 本轮设置 |
|---|---|
| 时钟 | 150 MHz 假设 |
| 共享权重源 | 512 KiB SRAM |
| 权重端口 | 4 B/beat；每 2 周期接受一拍；响应 3 周期；最多 2 outstanding |
| 权重带宽 | 稳态 2 B/cycle＝300,000,000 B/s，十进制 MB |
| 权重寄存器 | A 两组 16 B，共 32 B；B 两组 128 B，共 256 B |
| 权重 SRAM | 无，不启用 whole_matrix 缓存 |
| 公共局部存储 | 8 个 4096×16-bit 单端口宏，共 64 KiB |
| 局部带宽 | 合计最多 16 B/cycle，读写共享每个 bank 的端口；读取延迟 1 |
| 后处理 | 最多 8 通道/cycle，结果延迟 2；SRAM 请求另外仲裁 |
| LN 核心 | 行级事件 L=128、II=128、最多一行 |
| 格式 | A/W INT8；累加/bias INT32；残差合并后 LN 输入 INT16；gamma/beta INT16；输出 INT8 |

权重 128 B 包必须真实经历 32 个四字节拍。每拍维护字节有效掩码，完整数据到齐才可消费。允许返回同周期接受下一请求；乒乓寄存器可预取，但所有消费者完成前不能覆盖同一组。300 MB/s 只应用一次，不再附加一个未配置的本地权重 SRAM 带宽。

局部 SRAM 只保存激活、残差、完整 LN 前区域、输出及 B1 部分和。输入初装和布局排列的实际局部宏写入次数与周期单列。A 输入采用 k-major、token 填充到偶数；B 输入采用 row-major。相同原始权重按映射预先排成不同包布局，地址变换双射且预排布成本单列，不隐含免费转置。逐字节写掩码是假设，仍需真实宏规格确认。

## 四种调度

| 映射 | 发射组织 | 权重保留范围 | 主要状态 |
|---|---|---|---|
| A | 最多 9 token × 16 通道 × 1 归约元素 | 当前 k 的 16 B 广播九行 | 144×INT32＝576 B 累加器，两组九字节激活操作数 |
| B0 | 1 token × 2 通道 × 64 归约元素 | 严格当前 token，消费后替换 | 输入行 64/256 B，基本两个 INT32＝8 B 部分和 |
| B1_G9 | 同一包依次更新至多 9 token | 当前九 token 组 | 部分和 8×min(9,M) B 在公共 SRAM |
| B1_G99 | 同一包依次更新至多 99 token | 当前九十九 token 组 | 部分和 8×min(99,M) B 在公共 SRAM |

B1 减少权重重载，但每次发射重读 64 B 局部激活，至少四周期无冲突输入读取，并有部分和读改写与结果写入。未假定它能每周期发射。B1 的完整行必须等该行所有输出通道和残差就绪后才能进入 LN。

默认 FFN2 的共同有效张量容量为 25,344 B 输入＋6,336 B 残差＋12,672 B LN 前 INT16＋6,336 B 输出＝50,688 B。A 的偶数 token 填充、B1 的部分和与其他工作区另计。固定物理宏仍为 64 KiB；活跃量、预留容量和有效张量载荷分别报告，复用区域不重复计费。容量不足应直接判不可行，不悄悄把激活外溢到共享 SRAM。

## 周期与 LN 边界

每周期先应用已经到期的完成事件，再仲裁当前意图。权重端口与公共局部 SRAM 分开建模；激活读取、残差、部分和、LN 输入提取和输出写入争用相同局部 bank。预取数据、部分和和中间结果均有显式容量与依赖。

LN 启动前需要完整 64 通道、残差已对齐、输入全部提取到工作寄存器并预留输出空间。128 周期是固定核心处理事件；输入提取和输出写入确认在核心之外计时。相邻行核心启动至少间隔 128 周期，最多一行核心在处理。不能把旧分阶段统计/rsqrt/affine 延迟再次叠加到 128 上。

接口数值验证与时序分开。整数 GEMM、单次 bias、nearest-even 舍入、饱和和残差公共尺度有独立参考与测试；LN 为 Python 浮点参考公式，尚非位精确定点 LN。当前周期模拟运行形状、依赖、元数据请求与容量，不执行真实 checkpoint 的张量推理。

- `buffers.csv`、`initialization.csv` 保存预留/活跃峰值与主窗口外初始化账本。
- `report.html`、`comparison.md`、`assumptions.md` 提供可阅读结果及所有适用边界。
- `trace.jsonl` 仅在 `--trace` 时记录完整事件；默认文件为空。
- `arithmetic_baselines.json` 将新固定条件 L0 和旧预加载纯计算检查分别标记。
- `run_config.json`、`source_manifest.json`、`source/`、`invocation.json` 保存配置、哈希、源码和运行环境。

发射有效乘法器比例＝有效 MAC /（物理乘法器数×发射次数）。发射占空比＝发射次数 / 主窗口周期。端到端 MAC 利用率＝有效 MAC /（物理乘法器数×主窗口周期）。三者分开列示，不把低发射占空比误称为尾部无效乘法器比例。

SRAM 宏与寄存器载荷分别计账。寄存器预算尚不含全部控制、标签、地址生成、重排逻辑与互连；宏面积和标准单元面积未知时保持 null/unknown，不宣称满足 2.25 mm²。尚未获得真实 checkpoint 准确率、整网时延、RTL 一致性、官方库综合或能耗结论。
